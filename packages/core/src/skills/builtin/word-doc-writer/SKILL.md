# Word 文档

目标: **一次 `word_create` 调用**交出排版好的成品 .docx (中文字体、标题层级、项目符号、页码, 按领域的版式), 然后 `open_surface` 打开给用户看。

## 硬规则 (速度)

- 只调一次 `word_create`。**不要**写 python-docx / docx.js 脚本, **不要**转 PDF 核页数, **不要**用 LibreOffice。版式引擎已经管好字体、行距、缩进、页码。
- 用户说「2 页左右」只是篇幅参考: 按每页约 600–800 中文字 (公文每页约 600 字) 估算内容量即可, 不用核对实际页数。
- 用户没说篇幅时的常规长度: 通知 / 邀请函 1 页 · 周报 / 纪要 1–2 页 · 一课时教案 3–5 页 · 试卷 2–4 页 · 方案 / 报告 3–8 页 · 简历 1 页。写多了老师 / 领导不会看。
- 写完直接 `open_surface` 打开文件, 回复一两句说明做了什么、用了哪种版式。
- 要改已有的 .docx (用户给了模板 / 让你改某段) → 用 `word_get_paragraphs` + `word_edit_paragraph` / `word_replace_text` 这些编辑工具, 不要重建整份文件。
- 文件名用中文标题, 不要日期以外的多余后缀: `新员工入职指南.docx`。

## 选版式 (preset)

| 用户要的 | preset |
|---|---|
| 工作报告、方案、总结、周报月报、会议纪要、手册、说明书、调研报告 (非学术) | `report` |
| 通知、请示、报告、函、批复、纪要 (以单位 / 机关名义发文, 「关于…的通知」) | `gov` |
| 教案、教学设计、说课稿、班会方案、听课记录、教学反思 | `lesson` |
| 试卷、单元测试、练习题、作业单、学案 | `exam` |
| 论文、开题报告、课题结题报告、文献综述 | `academic` (自动带目录) |
| 合同、协议、规章制度、章程、承诺书 | `contract` |
| 邀请函、感谢信、申请书、证明、倡议书、个人 / 班级通知 | `notice` |
| 简历 | `resume` |
| 英文: business report, memo, proposal, cover letter, meeting notes | `business` |

拿不准就用 `report`。超过 6 个一级小节的长文档加 `toc: true`; 公司 / 学校文件可加 `header: "单位名称"`。

## 内容写法 (引擎认的语法)

- 第一行 `# 文档标题` → 居中大标题; `##` 一级标题, `###` 二级, `####` 三级
- `- 条目` → 真项目符号; `1.` `1、` `（1）` 开头的行保留编号
- `[center] 文字` 居中 (副标题、考试说明); `[right] 文字` 靠右 (落款、日期)
- `> 文字` → 灰底提示框 (注意事项、温馨提示)
- `| 表头 | … |` 表格, 第一行自动加底色; `**加粗**`; 单独一行 `\newpage` 分页

## 各领域的结构 (国内习惯优先)

**周报 / 月报 / 总结**: `# 2026年第43周工作周报` → `[center]部门 · 姓名 · 日期` → `## 一、本周完成` (列表, 带量化结果) → `## 二、数据` (表格) → `## 三、问题与风险` → `## 四、下周计划` (表格: 事项 / 负责人 / 截止)。

**会议纪要**: 标题 → 信息表 (时间 / 地点 / 主持 / 参会人 / 记录人) → `## 一、会议议题` → `## 二、讨论情况` → `## 三、会议决定` → `## 四、待办事项` (表格: 事项 / 责任人 / 完成时间)。

**公文 (gov)**: 标题「关于××的通知」(不加书名号) → 主送机关一行「各部门、各单位：」(顶格写在普通段落, 引擎会缩进, 可接受) → 正文开头说明目的依据 → 「现将有关事项通知如下：」→ 层级严格用 `## 一、` `### （一）` 然后正文里 `1.` `（1）` → 结尾「特此通知。」→ `[right]发文单位` `[right]2026年10月21日` (日期用阿拉伯数字, 年月日写全)。附件写在正文之后: 「附件：1. ××」。

**教案 (lesson)**: 标题「《课题》教学设计」→ 基本信息表 (课题 / 年级 / 课时 / 授课教师 / 课型) → `## 一、教材分析` `## 二、学情分析` `## 三、教学目标` (知识与技能 / 过程与方法 / 情感态度价值观, 或新课标「核心素养」写法) `## 四、教学重难点` `## 五、教学准备` `## 六、教学过程` (每个环节 `### （一）导入新课（5分钟）`, 写清教师活动、学生活动、设计意图, 环节多时用表格: 环节 / 教师活动 / 学生活动 / 设计意图) `## 七、板书设计` `## 八、作业布置` `## 九、教学反思`。

**试卷 (exam)**: 标题「2026—2027学年第一学期期中考试 七年级数学」→ `[center]（满分100分，考试时间90分钟）` → 可选信息栏 `[center]班级：______ 姓名：______ 学号：______` → 题型分区 `## 一、选择题（每题3分，共30分）` → 题号全卷连续 `1.` `2.`…, 选择题选项写在下一行 `A. … B. … C. … D. …` (用全角空格隔开), 填空用 `______`, 解答题注明分值 → 需要答案时 `\newpage` 后 `## 参考答案`。分值加起来要等于满分。

**论文 (academic)**: 标题 → `[center]作者 · 单位` → `**摘要：**…` `**关键词：**…；…；…` → `## 1 引言` `## 2 …` (学术论文用阿拉伯数字层级 `## 2` `### 2.1`) → `## 参考文献` (`[1] 作者. 题名[J]. 刊名, 年, 卷(期): 页码.` GB/T 7714 格式)。

**合同 (contract)**: 标题「××合同」→ 合同编号 `[right]合同编号：____` → 甲乙方信息表 (名称 / 地址 / 联系人 / 电话) → 鉴于条款一段 → `## 第一条 合同标的` `## 第二条 价款与支付` … `## 第×条 违约责任` `## 第×条 争议解决` `## 第×条 其他` → 签署栏表格 (甲方 / 乙方 两列: 盖章、代表签字、日期)。

**简历 (resume)**: `# 姓名` → `[center]电话 · 邮箱 · 城市` → `## 教育背景` `## 工作经历` (`**公司** · 职位 · 起止时间`, 下面 2–4 条带数字的成果) `## 项目经历` `## 技能` `## 证书 / 荣誉`。控制在一页。

**邀请函 / 申请书 / 证明 (notice)**: 标题 → 称呼顶格「尊敬的××：」→ 正文 → 结尾敬语 → `[right]单位 / 署名` `[right]日期`。

**英文商务 (business)**: Title → `[right]Prepared by … · Month YYYY` → `## Executive Summary` (3–5 bullets with numbers) → sections → `## Next Steps` (numbered, owner + date). 句子短, 不缩进 (引擎已处理)。

## 质量

- 内容要具体: 数字、日期、负责人、可执行的动作; 不写「等等」「相关工作」这类空话。
- 用户没给的事实 (公司名、人名、数据) 用合理占位并在回复里说一句「×× 是示例, 请替换」, 不要编造成真数据。
- 表格用于并列信息 (日程、对比、分工、评分标准), 别把大段正文塞进表格。
- 中文正文用全角标点 (，：；（）), 数字和英文用半角。公文不传 header (规范里没有页眉)。
