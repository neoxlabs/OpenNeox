# 场景骨架 (区块顺序照抄, 内容换成用户的)

## 落地页 / 官网首页 (business · tech-dark · edu)
1. **导航**: logo 字标 + 3–5 个锚点 + 右侧主按钮; 吸顶时加半透明背景 `backdrop-filter:blur(12px)`。
2. **首屏**: 一句不超过 16 个字的主张 (说结果, 不说「领先的…平台」) + 一句副标题 + 主次两个按钮 + 右侧 / 下方一张产品示意 (用 HTML/CSS 画的界面框, 不是空白占位图)。
3. **信任条**: 客户 / 合作方名字 (文字 logo 灰色排一行) 或 3 个硬数字。
4. **能力**: 3–6 条, 每条 = SVG 图标 + 4–8 字标题 + 一句具体说明; 交替的图文左右排比一排三卡更有设计感。
5. **怎么用**: 3 步编号流程。
6. **案例 / 评价**: 1–3 段带人名职位的引用。
7. **价格** (有就放): 2–3 档, 推荐档描边加标签。
8. **FAQ**: `<details>` 折叠 4–6 条。
9. **收尾行动**: 大号一句话 + 主按钮; 页脚联系方式。

## 产品 / 课程介绍页 (business · edu)
首屏 (产品名 + 一句价值 + 关键参数 3 个) → 痛点 (用户现在的麻烦, 3 条) → 方案 (怎么解决, 配示意) → 详细功能 / 课程大纲 (时间线或分章列表) → 适合谁 / 讲师介绍 → 价格与报名 → FAQ。

## 活动 / 邀请 H5 (event · guochao)
移动优先。首屏大标题 + 日期 (超大数字) → 倒计时 → 活动亮点 (3 张色块卡) → 嘉宾 (圆形头像用渐变色块 + 首字) → 日程 (时间轴) → 地点 (地址 + 「复制地址」按钮, 不嵌地图) → 底部固定报名按钮; 报名表单: 姓名 / 手机 (校验 11 位) / 单位, 提交后显示成功卡片 (前端演示, 说明未接后端)。

## 个人主页 / 在线简历 / 作品集 (minimal · editorial)
名字 + 一句定位 + 联系方式 → 精选作品 (网格, 点开放大用 `<dialog>`) → 经历 (时间线: 年份 · 公司 · 职位 · 一句成果) → 技能 (标签) → 联系。简历版加「打印」按钮并写 `@media print` (隐藏按钮, 黑白, A4 一页)。

## 数据看板 (dashboard)
标题栏 (名称 + 日期范围选择 + 刷新时间) → KPI 4 个 → 主趋势图 (占 8 栅格) + 构成图 (4 栅格) → 排名表 (前 10, 带迷你条形) → 明细表 (可排序)。数据写在 `<script>` 里的一个数组, 图表和表格都从它算, 不要各写各的数。

## 知识卡片 / 学习资料页 (edu · editorial)
标题 + 学习目标 → 核心概念卡 (定义 + 例子 + 易错点) → 图解 (SVG 流程 / 对比图) → 小测 (单选, 点选后即时显示对错和解析) → 总结要点 (3–5 条) → 延伸阅读。适合老师发给学生; 字号放大 1 档。

## 单页小工具 (business · minimal · tech-dark)
居中一张工具卡: 标题 + 一句用途 → 输入区 (带标签、单位、默认值) → 主按钮 → 结果区 (大号结果 + 计算说明) → 历史记录 (localStorage, 可清空)。键盘可用 (回车提交), 错误输入就地提示。

## 课堂互动 / 投屏 (edu · event): 选座、点名、抽签、分组、计分
老师在讲台电脑上操作、投屏给全班看 —— **要有现场感和仪式感**, 不是后台表格。
- **按投影设计**: 1440 宽一屏放下不滚动, 字大 (当前人名 64px+, 座位上名字 18px+), 对比强; 加「全屏」按钮 (`requestFullscreen`)。
- **画真实的东西**: 给了教室照片就**先看图**数清组数 / 每组列数 / 排数 / 过道 / 讲台黑板在哪头 / 门窗在哪侧, 回复里一句话复述 (「照片是 3 组 × 2 列 × 7 排, 黑板在前, 左边靠窗」); 座位的组 / 列 / 排 / 过道和照片一一对应, 窗、门在哪侧用小字标出, 把照片缩略图放角落作对照; 座位画法见下面「课堂风格」, 不要一格格空白方框。
- **两步流程 (选座这类必须这样分页)**: ① **名单页** —— 全班学生卡片网格 (序号 + 名字, 已选的卡变灰打勾, 不写座位号), 老师 / 学生点自己的名字; ② 点名字后**切换到选座页** —— 整屏只剩教室座位图 + 顶部「XXX 请选座位」, 点座位 → 确认卡 (「确定坐 第 3 排第 2 座？」确定 / 换一个) → 确定后名字飞进座位、1 秒后自动回到名单页等下一位。页面切换用淡入 + 轻微位移。不要把名单和座位图挤在同一屏让人边看名单边选。
- **当前轮到谁是主角**: 选座页顶部大号「请 XXX 选座位」名牌卡 (头像用名字首字圆形色块); 换人时名牌翻转 / 滑入。
- **关键时刻要有动效**: 选定座位时名牌**飞进座位** (FLIP: 记录起点终点, transform 过渡 500–700ms) + 座位轻弹一下 + 小范围彩纸 / 光点; 抽签名字快速滚动后减速停下。动效只用 transform / opacity。
- **隐私** (后面的人看不到前面的人坐哪): 藏的是**谁**坐那, 不是**有没有人**坐 —— 已选座位要一眼看出来 (桌上出现书包 / 人形剪影 / 色块 + 「已选」), 名字默认隐藏, 一键切换显示 / 隐藏。
  **隐藏时整屏任何地方都不能出现「人 ↔ 座位」的对应**: 学生是站在屏幕 / 平板前看的, 名单里只写「✓ 已选」不写「1排3座」, 提示条 / toast 只说「已选好, 请下一位」, 鼠标悬停不弹名字; 座位号只在「揭晓」或老师点开显示后才出现。
- **收尾揭晓**: 全部完成后有「揭晓座位表」按钮, 座位按排依次翻开显示名字 (每格错开 30–50ms), 这是投屏最出彩的一刻; 附打印 / 导出 Excel(CSV)。
- 进度条 (已选 N / 总数)、撤销、重置 (二次确认); 状态存 localStorage, 刷新不丢。
- **老师的操作要齐**: 点学生弹操作卡 (让 TA 重新选座 / 老师直接换座位 / 取消 TA 的座位 / 改名字); 座位可标「空置」(不可选); 「生成座位表图片」(canvas 画出来下载 PNG) 与打印。

**课堂风格 (默认参考; 用户点名了风格, 或你有更好的整体设计, 就按你的来)**。不管用哪套, 这几条是底线: 空座和已选**一眼分得开** (空座亮、已选实心深色), 座位不能和底色同色系糊成一片 (10-21 米色底配米色座位, 用户原话「丑爆了」), 只用一个强调色, 座位要有形状和层次、不是空白方框。没有更好的想法就照下面这套:
```css
:root{--bg:#F3F0E9;--paper:#FBFAF6;--ink:#1F2A24;--muted:#8A8A80;--line:#E6E1D6;--green:#2E6B4F;--green-deep:#1F4D39;--gold:#C9A45C;--seat-empty:#FFFFFF;--seat-edge:#C9D3CD;--seat-arm:#F4F7F5;--danger:#C0453A;--font-head:"Songti SC","Noto Serif SC",STSong,serif}
body{background:radial-gradient(1200px 600px at 80% -10%,#fff8 0,transparent 60%),linear-gradient(180deg,#F6F3EC,#EEEAE1)}
```
- 顶栏: 左边班级名 (衬线) + 右边「已选 N / 总数」大数字; 顶栏下一条 1px 渐变细线 (绿 → 金)。
- 大标题衬线、字距 .08em (「请 彭子墨 上台选座」「全部 42 人已入座」); 主按钮深绿实心带柔和阴影, 次按钮米色底。
- 讲台画成座位区上方一条**金色细弧线** + 「讲 台」小字, 不是一条深色横幅。
- **座位 = SVG 小沙发椅** (靠背 + 坐垫 + 两侧扶手), 不是方框: 空座白底米色描边; 已选深绿填充、名字白字压在靠背上 (隐藏名字时显示「已选」); 空置虚线描边 + ×。排号写在两侧, 列号写在上方, 过道留宽。底部图例 (可选 / 已有人 / 空置)。
```html
<svg viewBox="0 0 80 72" class="seat"><rect x="14" y="4" width="52" height="40" rx="12" class="back"/><rect x="4" y="30" width="14" height="36" rx="7" class="arm"/><rect x="62" y="30" width="14" height="36" rx="7" class="arm"/><rect x="16" y="42" width="48" height="24" rx="8" class="cushion"/></svg>
<style>.seat .back,.seat .cushion{fill:var(--seat-empty);stroke:var(--seat-edge);stroke-width:2}.seat{filter:drop-shadow(0 2px 4px rgba(31,77,57,.10))}.seat .arm{fill:var(--seat-arm);stroke:var(--seat-edge);stroke-width:2}.taken .seat .back,.taken .seat .cushion{fill:var(--green);stroke:var(--green-deep)}.taken .seat .arm{fill:var(--green-deep);stroke:var(--green-deep)}</style>
```
- **质感升级 (给了教室照片就做)**: 改图工具默认不在手边, 先 `tool_search("改图")` 解锁 `edit_image` (搜不到就跳过这步); 用它把教室照片改成**俯视 3D 渲染的空教室底图** —— prompt 要点: `top-down 3/4 isometric architectural render of this classroom, same layout of walls / windows / door / blackboard / podium, EMPTY floor (no desks, no chairs, no people), soft daylight, light wood floor, clean minimal interior, high detail`, 横图 1536x1024, 存到页面同目录 `classroom-bg.png` 并用相对路径引用。座位**不画进图里**: 页面上一个 `aspect-ratio:3/2` 的容器铺底图, 座位用百分比绝对定位叠上去 (按照片的组/列/排算 left/top), 这样位置可控、随窗口缩放。座位卡做成小相框: 已选 = 名字首字圆形头像 (按姓名哈希取 6 色之一) + 「已选」角标, 空座 = 白卡 + 座号; 带细阴影。出图失败就退回上面的 SVG 沙发椅平面图, 不要卡住。
- **完全自适应 (必须)**: 页面会在任意大小的窗口里打开 —— 投屏、笔记本、侧边预览窗、学生手里的平板、手机, 窗口还会被随时拖大拖小。不按几个固定宽度做断点适配, 而是**流式布局**: 所有尺寸跟着可用空间连续变化 (`fr` / `%` / `minmax(0,1fr)` / `clamp()` / `min()` / 容器查询 `@container` + `cqi` 单位), 座位用 `aspect-ratio` 定形、跟着格子缩放, 不写任何固定 px 宽高的座位卡或面板。**座位图在任何尺寸下都完整可见, 不横向溢出、不被裁**; 空间不够并排时, 名单自动让位 (折叠到下方 / 抽屉), 座位图优先。
- 名单区: 4 列学生卡 (序号 + 名字 + 右侧「✓ 3排6座」绿色小胶囊), 上方「全部 / 待选 / 已选」分段筛选。

## 长图文 / 报告页 (editorial · business)
封面区 (大标题 + 作者日期) → 目录 (锚点) → 正文章节 (单栏 680px, 小标题 + 正文 + 数据图 / 引用穿插) → 结论 → 附录 / 来源。图表用 SVG 或 ECharts, 每张图下有一句「这说明…」。
