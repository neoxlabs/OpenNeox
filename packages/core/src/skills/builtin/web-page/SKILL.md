# 做网页

交付物: **一个自包含的 `.html` 文件**, 双击就能打开 —— CSS / JS 内联, 不要构建步骤, 不要本地素材文件。
它必须**像设计师做的, 不像 AI 生成的**。scenes.md 里的**流程、隐私、自适应、质量底线是必须遵守的**; styles.md 的风格预设和 scenes.md 的视觉参考是**默认起点** —— 用户点名了风格, 或你有更好的整体设计, 就按你的来, 只要满足底线。

## 流程 (目标: 2–3 分钟内交付, 总共不超过约 8 次工具调用)

1. **定一句话**: 给谁看、看完要做的唯一一件事 (报名 / 购买 / 联系 / 了解)。这句话决定版面重心。
2. **选风格** (styles.md 8 选 1) + **选场景** (scenes.md): 按用户话里的行业、受众、气质选; 用户点名了颜色 / 品牌色就以它为主色重配一套。
   回复里一句话说明选了什么 (「用『清新教育』风格做成课程介绍页」)。
3. **一次写完整个文件** (一次 write_file, 样式 + 结构 + 数据 + 脚本全在里面)。不要先写骨架再分几次补数据层、渲染逻辑 —— 10-21 实测看板分 3 次写, 光写就多了 2 分钟。配色字号先定成 `:root` token (用预设就抄预设), 再按骨架写区块。
   示例数据写之前就想好: 数字要有真实感的参差 (别让两行算出同一个数), 对比口径一致 (本月 20 天就跟上月同期 20 天比)。
4. **自查用 `check_page`** (后台渲染, 一次调用拿回 1440 / 768 / 390 三个宽度的截图 + 溢出 / 报错清单; 要看点击后的状态用它的 `click` 参数), 不要开浏览器一步步点。对照截图和 craft.md 末尾的清单, **把看到的问题列全, 合并成一次修改改完**。**最多两轮**, 第三轮的小瑕疵写进回复让用户决定。
   **改完不再截图复核**, 直接第 5 步交付 —— 复核会发现新的小瑕疵, 再改再截, 停不下来 (10-21 官网修到第 5 轮还在截 7600px 长图)。
   不做逐项交互实测 (点排序、切深色、校验标签闭合、逐行核数字) —— 这些是用户要上线时的事。10-21 实测看板、官网各因此跑了 7 分钟, 截图一轮就够的页面。
5. `open_surface` 打开给用户, 回复两三行: 文件位置、页面里有什么、哪些内容是示例待替换。

## 硬规则

- **内容用用户的真东西**。没给就按他的主题写可信的具体文案 (真实的数字、场景、名字), 不写 lorem ipsum、「功能一 / 功能二」、「为您提供优质服务」这种空话; 回复里说明哪些是示例。
- **国内打开要快**: 不用 Google Fonts (国内打不开, 页面会卡住或掉回默认字体)。字体用 styles.md 里的系统字体栈。
  确实要库时只用 `https://cdn.jsdelivr.net/npm/<包>@<固定版本>/…` (国内外都能访问), 图表用 ECharts (`echarts@5.5.1/dist/echarts.min.js`); 能用原生 CSS / SVG 做的不引库, 不用 Tailwind CDN (运行时编译, 首屏慢)。
- **图标用内联 SVG** (线性风格, 统一 1.75 描边), 不用 emoji 当图标。图片优先用 CSS / SVG 画的图形、渐变块、数据图; 要照片时用用户给的, 或 `https://images.unsplash.com/photo-…?w=1600&q=80` 直链并写好 `alt`。
- **完全自适应**: 窗口任意大小、随时拖动缩放都要好看 —— 用流式布局 (`fr` / `%` / `clamp()` / `min()` / `@container`), 不靠几个固定断点、不写死 px 宽的大块; 任何宽度都没有横向滚动, 内容不被裁; 按钮 ≥ 44px 高, 字号不小于 14px。
- **深浅色**: 预设已给好 `prefers-color-scheme: dark` 的 token; 活动 H5 / 国潮这类品牌色强的页面可以只做浅色。
- **动效克制**: 只动 `transform` / `opacity`, 150–300ms, ease-out; 进场最多一处; 包在 `@media (prefers-reduced-motion: no-preference)` 里。
- 中文排版: 正文 16–17px、行高 1.7–1.8、段落最长约 36 个汉字; 中英文之间留空格; 用全角标点。

## 小工具 / 游戏 / 看板

- 小工具 (计算器、倒计时、抽奖、问卷): 先让它**能用**, 输入有校验、结果醒目、可以重置; 状态存 `localStorage` 时包 try/catch。
- 数据看板: 用 dashboard 预设; 图表配色用预设里的数据色板, 数字 `font-variant-numeric: tabular-nums`; 每张图配一句结论标题, 不只写「销售趋势」。
- 小游戏走 mini-game 技能, 动画讲解走 animation 技能。
