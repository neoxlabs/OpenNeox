## 存储 (Storage)

管理应用数据占用空间和清理无用文件。

### 总占用概览

页面顶部显示总存储占用大小，以分段条形图和图例展示各类数据占比：

| 分类 | 说明 |
|------|------|
| 代码回退 | Checkpoint 快照，用于撤销代码变更 |
| 数据库 | neox.db 等应用数据库 |
| 工作区 | 本地项目工作区缓存 |
| 旧会话 | 历史对话记录 |
| 配置 | JSON 配置文件 |

点击 **打开目录** 按钮可在 Finder 中打开主配置目录。

### 清理

**代码回退数据**

显示当前所有项目的 Checkpoint 数据总占用。

- **一键清理** - 删除所有项目的代码回退快照，清理后该项目的代码变更无法回退，请谨慎使用。

### 高级

展开后显示以下详细信息：

#### 数据路径

列表显示各类数据的存储位置：

| 项目 | 路径说明 |
|------|---------|
| 主配置 | ~/.neox/（或对应平台用户目录） |
| 日志 | 配置目录下的 logs 子目录 |
| 工作区 | 配置目录下的 workspaces 子目录 |
| 回退快照 | 项目根目录下的 .cdundo/ 目录 |

支持点击 **Finder 图标** 在 Finder 中打开非相对路径的目录。

#### 文件明细

列表显示所有配置文件和子目录，支持：

- **展开目录** - 点击目录行展开查看内容
- **预览文件** - 点击 JSON 配置文件打开预览模态框，自动格式化展示
- **在 Finder 中打开** - 点击文件行右侧的外链图标

文件预览模态框支持：
- JSON 自动缩进格式化
- 右上角 Finder 链接和关闭按钮

#### 代码回退（按项目）

列表显示各项目的代码回退数据占用，支持逐项清理：

- 显示项目名称、路径、占用大小
- **清理** - 点击垃圾桶图标删除该项目的回退数据

## 关于 (About)

查看版本信息、检查更新、访问官方链接、开启开发者模式。

### 版本信息

页面顶部显示 Neox 应用标志和版本号。

- **版本号** - 格式：v{版本} · {平台} · {架构}，例如 v2.0.1 · darwin · arm64
- **开发者模式标记** - 开启开发者模式后右侧显示 DEV 标记

**隐藏技巧**：连续点击版本号 7 次可开启开发者模式。开启后会提示倒计数。

### 更新

自动检查新版本发布，支持下载和安装更新。

#### 检查更新

点击 **刷新图标** 检查是否有可用更新。

检查结果展示：

| 状态 | 说明 | 操作 |
|------|------|------|
| 检查中 | 正在连接服务器 | 禁用按钮 |
| 有新版本 | 显示版本号升级路径（当前版 → 新版） | **立即升级** 按钮 |
| 已是最新版 | 当前版本已为最新 | 无额外操作 |
| 检查失败 | 网络错误或服务问题 | 显示错误信息 |

#### 安装更新

点击 **立即升级** 后：

1. 下载新版本安装文件
2. 显示下载进度（百分比、已传输/总大小、下载速度）
3. 下载完成后自动重启安装

进度指示：
- 百分比进度条
- 实时下载速度（例如 2.5MB/s）
- 已传输/总大小（例如 50.2MB / 100.5MB）

快速访问官方资源：

| 链接 | 目标 |

### 开发者选项

需要先开启开发者模式。也可使用快捷键 **Cmd+Shift+Alt+D** 快速切换。

#### 诊断日志

开关用于排障时输出详细日志，协助技术支持定位问题。

- **Off** - 仅记录基本日志
- **On** - 记录详细诊断信息

**注意**：更改后需重启应用才能生效。
